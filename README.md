## 🚀 Key Features

- ⚡ **Interactive Typing Effect**: Dynamic JavaScript typewriter greeting in the hero banner.
- 🎨 **Modern Dark Aesthetic**: Slate and cyan color scheme (`#0f172a` / `#38bdf8`) with smooth CSS transitions.
- 📜 **Scroll Reveal Animations**: Dynamic intersection-based element reveal animations as you browse.
- ✨ **Pure CSS Floating Elements**: Lightweight floating background particles without heavy JS libraries.
- 📱 **Fully Responsive Layout**: Fluid Flexbox & Grid architecture that displays seamlessly across mobile, tablet, and desktop screens.
- 📬 **Serverless Contact Form**: Direct message delivery powered by FormSubmit.co with anti-spam protection.
- 📄 **Instant Resume Access**: Direct one-click PDF resume download button for recruiters and hiring managers.

## 💻 Local Development Setup

To run or customize this portfolio on your local machine:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/Martin0610/Portfolio.git
   cd Portfolio
   ```

2. **Run Locally:**
   - Simply double-click `index.html` to open it in any browser, or
   - Using Python's built-in HTTP server:
     ```bash
     python -m http.server 3000
     ```
   - Open your browser at `http://localhost:3000`.

---

## ⚙️ Customization Guide

- **Personal Info**: Update your biography and details in `index.html` under the `<section id="about">` block.
- **Projects**: Add or update cards under the `<section id="projects">` grid container.
- **Resume**: Replace `MJV RESUME.pdf` with your latest resume file and ensure the download link matches the filename.
- **Contact Form**: Update the email address in `action="https://formsubmit.co/your-email@gmail.com"` inside the form tag.
